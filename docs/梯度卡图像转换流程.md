# 用梯度卡做图像转换：完整操作流程

> 依据 Lumina Studio 官方 Wiki（wiki.luminastudio.com.cn）2026-07-28 版本页面整理。
> 官方「使用耗材档案完成图像转换」独立教程尚未发布，本文由 Wiki 各页参数与顺序串联而成。
> 软件仍在更新，最终以界面上实际显示的文字为准。

---

## 最短路径（先看这 7 步）

1. **设置** → 选好你实际的切片软件、打印机型号、喷嘴尺寸
2. **耗材管理 → 梯度卡生成** → 选层高 → 生成并下载 Kit ZIP
3. 打**白底 + 黑底**两张卡（同一卷料、同层高、同配置）
4. **耗材管理 → 梯度卡提取** → 传 ZIP + 两张照片 → 点四角 → 保存到**耗材库**
5. **图像转换** → 上传图片 → **来源类型选「耗材档案」**
6. 选手上的耗材 + 叠色层数 + 层高 + 底板耗材 → **预览** → 检查
7. **生成** → 在切片软件里按完整项目打开 → 逐层核对 → 打印

---

## 阶段一：把梯度卡变成「耗材档案」（一次性）

梯度卡本身不能直接转换图像，必须**先提取成耗材档案并保存到耗材库**。

| 步骤 | 位置 | 要点 |
|---|---|---|
| 1 | 耗材管理 → 梯度卡生成 | 层高选 0.04 / 0.08 / 0.10 mm，**首次用 0.08** |
| 2 | 同上 | 生成并下载 **Kit ZIP**（含 3MF、层序配置、提取参数、说明） |
| 3 | 切片软件 | 打两张卡：**白底一张、黑底一张**，同一卷待测耗材、同层高、同配置、同方向 |
| 4 | 耗材管理 → 梯度卡提取 | 上传 Kit ZIP + 白底照片 + 黑底照片 |
| 5 | 同上 | 四角顺序 **左上 → 右上 → 右下 → 左下**，两张共 8 次 |
| 6 | 同上 | 检查透视校正预览、方向检测置信度、提取警告 |
| 7 | 同上 | 填耗材名称 → 保存耗材档案 → 在**耗材库**确认出现 |

**红线**

- 层高**不能事后改**；提取以 Kit ZIP 中的配置为准。
- **0.08 mm 的档案不能当成 0.04 mm 数据用。**
- 平均 ΔE **大于 3** 说明拟合不可信，先修照片/角点再提取。
- 旧教程「平均 ΔE 低于 2 就一定精准」**已被官方修正**，不要只盯一个数字。

## 阶段二：图像转换

### 1. 上传图片

- 支持：JPEG、PNG、SVG、WebP、HEIC/HEIF、RAW（DNG/CR2/CR3/NEF/ARW/ORF/RW2/RAF/PEF/SRW）、`.lumina.json`
- 可拖拽上传；「上传后裁剪」可开裁剪窗口（自由比例 / 1:1 / 4:3 / 3:2 / 16:9 / 9:16 / 3:4）
- 旋转：选 90°/180°/270° 后**必须点「应用旋转」**
- 更换、裁剪或旋转后，旧预览作废，**要重新点「预览」**

### 2. 来源类型 → 选「耗材档案」

这是最关键的一步。三种来源不是同一数据的三种显示：

| 来源类型 | 用什么数据 | 本文场景 |
|---|---|---|
| 传统 LUT | 预生成的颜色–配方查找表（1.x 遗留） | ✗ |
| 反推 LUT | 品牌包的数据库与参考组 | ✗ |
| **耗材档案** | **从梯度卡提取、存在耗材库中的单卷实测档案** | ✓ |

> **不要把耗材档案文件当作传统 LUT 上传。**
> 切换来源会清除旧预览、3MF 和下载链接，必须重新预览。

### 3. 耗材档案模式的四项参数

| 参数 | 说明 |
|---|---|
| **选择耗材** | 打开耗材库；**列表顺序 = 配方中的材料槽顺序**。更换/删除/重排都会使旧预览失效 |
| **叠色层数** | 界面 5–10 层，生成接口接受 1–20 层。这是**每个像素配方可用的打印层数，不是耗材卷数**——五卷料也能算十层配方 |
| **层高** | 0.04 / 0.08 / 0.10 mm，**必须与档案标定层高一致** |
| **底板耗材** | 只能从已选耗材中选；原选择被移除时软件会重新推断默认值 |

层数增加 → 候选组合变多、模型更高、求解更慢。

### 4. 求解缓存（可选，组合大时必需）

| 类型 | 作用 | 档位 |
|---|---|---|
| **穷举缓存** | 精确枚举当前组合的完整配方库 | 完整枚举 |
| **智能配方缓存** | 覆盖范围较广的候选集合 | 100万 / 400万 / 800万 / 3200万 / 6400万，默认 3200万 |

- 缓存身份包含：**耗材及排列顺序、叠色层数、层高、基底类型、Lab 网格精度**——任一项变化就查另一份缓存。
- 转换时优先用穷举缓存，没有才用智能配方缓存。
- ⚠️ **两类缓存都不会修正不准确的耗材测量**，也不改变层序和光学计算规则。**测量质量就是精度上限。**

### 5. 尺寸与结构

| 项目 | 范围 / 默认值 |
|---|---|
| 成品宽度 / 高度 | 普通模式 **10–400 mm**；开大画幅上限到 9999 mm。改宽度会按原图比例联动高度 |
| 底板厚度 | 默认 **1.20 mm**，界面 **0.24–3.44 mm**，步进 0.08 mm（生成接口 0.20–3.50 mm） |
| 结构模式 | **双面**（正反都有图案）/ **单面**。开启浮雕或冰箱贴会强制单面；五色扩展不允许双面 |
| 建模模式 | 高保真（约 10 px/mm）/ 像素艺术（按喷嘴线宽）/ 矢量（仅 SVG）/ **验证色卡**（测梯度卡准度用） |
| 量化颜色数 | 默认 **48**，未解锁范围 **8–256**，步进 8；解锁后最高 8192 |

底板厚度**不含**彩色叠层、浮雕额外高度或透明镀层，总高度要分别相加。

### 6. 预览 → 检查 → 生成

**预览** 会建立新会话，产出 2D 预览、3D 模型预览、调色板/分层图/颜色工作站数据。
**生成** 只在当前预览会话有效时可用。

底部主按钮的实际动作：

| 状态 | 点击后 |
|---|---|
| 已检测到切片器、尚未生成 | 先生成 3MF，再在所选切片器中打开 |
| 已检测到切片器、已有 3MF | 直接把当前产物交给切片器 |
| 未检测到切片器 | 生成并下载 3MF |
| 大画幅模式 | 生成含多片 3MF 的 ZIP，不自动打开 |

### 7. 分层预览怎么读

> **第 1 层是观赏面，编号越大越靠近底板。**
> 这个「第 1 层」**不是**切片器从打印板算起的第一个物理打印层。

逐层检查顺序：轮廓是否完整 → 关键细节是否还在 → 颜色变化是否符合配方 → 层数是否正确 → 修改是否生效。

- 悬停主预览任意位置会显示：放大镜、像素坐标、**预测颜色**、第 1–N 层颜色。
- 预测色通常**不等于任何单层色**，也不是几个 HEX 的简单平均。
- ⚠️ 缩略图白底会造成误会：**白色耗材可能与页面背景融在一起**，放大后看棋盘格（棋盘格=透明背景）。

### 8. 颜色工作站（按需微调）

- **耗材档案**模式下，右侧「目标颜色」显示的是当前耗材组合**能求解出的候选颜色**，不是固定 LUT 色表。
- 输入 3 位或 6 位 HEX（如 `#8CE`、`#88CCEE`）→ 返回**最多 20 个候选，按 ΔE00 从近到远**，候选间保留最小色差。
- 只有点**「确认替换」**才会重建 2D/3D 预览；「取消」只清除待确认项。
- 查询来源会标明：缓存命中 / 运行时命中（3200万）/ MITM 实时求解（最多 200万组合）。
- ΔE 是**模型预测差**，不是对实体打印误差的保证。

## 阶段三：切片软件里必查（8 步）

1. **作为完整项目打开** 3MF——不要选「只导入模型/几何数据」
2. 核对**打印机型号和喷嘴尺寸**
3. 分清四种信息：项目耗材 / 对象耗材分配 / 真实耗材 / 实际料槽
4. 核对**项目耗材列表**（看材料类型，不只看颜色）
5. 逐个检查**对象和零件的耗材分配**
6. 把项目耗材对应到**真实料槽**
7. 执行真实切片 → 进「**预览**」，按耗材查看
8. 翻到**显色面**，拖动层滑块逐层检查

> 准备页面看起来对，**不能代替**切片后的逐层预览。
> 对象列表里的「3」不代表必须放进 AMS 3 号槽。

## 出问题时的固定排查顺序

先判断差异属于哪一层，**前一项没确认前不要跳到后面用温度/流量/修图补偿**。

| 现象 | 优先判断 | 能否继续打印 |
|---|---|---|
| 切片器色块不像真实线材，但对象和槽位都对 | 可能只是屏幕显示色 | 可以 |
| 对象/颜色/底板被分到错误耗材或料槽 | **真实映射错误** | **不要打印**，先修映射 |
| 两种预览都正常，实物整体偏色 | 档案、线材批次、打印状态、观察光线 | 先打小样排查 |
| 小字、细线、小色块切片后消失 | 尺寸、喷嘴、线宽、路径生成 | 不要靠正式打印碰运气 |
| Lumina 预览就全黑/偏绿/破洞 | 来源、输入图、模式 | 不要生成正式作品 |

排查七步：确认版本与来源档案 → 核对真实耗材和槽位 → 确认喷嘴/线宽/层高/尺寸 → 检查 Lumina 预览 → 真实切片看显色面 → 查首层/流量/板面/机器状态 → 最后才比较观察光线和照片。

**建议保留的复现资料**：原始输入图片/SVG、来源类型与档案名称及材料顺序、Lumina 二维与三维预览截图、导出的原始 3MF、切片器显色面与关键层截图、打印机/喷嘴/层高/线宽/真实料槽记录、中性光下拍的实物照片。

## 高频坑清单

- 拿别的耗材照片去配这个 Kit ZIP，或只上传从 ZIP 里单独取出的 3MF
- 只拍白底卡或黑底卡（**不行，必须成套**）
- 拍照时开滤镜、美颜、AI 增强，或两张照片换设备/换白平衡
- 事后在提取页面改层高
- 把耗材档案当传统 LUT 上传
- 为了让槽位编号看起来一致而随意移动线盘
- 第一次建好档案就直接打大型作品（**应先打小测试图**）
- 用手机照片和未校准的屏幕截图判断几度色差
